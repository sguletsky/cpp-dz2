# ДЗ-2. Парк техники

Консольная программа на C++17. До техосмотра техникой владеет `unique_ptr`. Парк хранит принятые единицы в `vector<shared_ptr<InventoryItem>>`. Витрина использует `weak_ptr`.

## Сборка и запуск

Открой папку проекта в CLion и запусти цель `dz2` или выполни в терминале macOS/Linux следующие команды.

```sh
cmake -S . -B build
cmake --build build
./build/dz2
```

## Команды

- `add ID ok Название` принимает технику в парк.
- `add ID fail Название` имитирует отказ на техосмотре.
- `list` выводит список техники.
- `focus ID` выбирает технику для витрины.
- `show_focus` показывает выбранную технику или выводит `expired`, если витрина пуста.
- `remove ID` удаляет технику из парка.
- `quit` завершает программу.

## Проверка

Введи в консоли запущенной программы эти команды.

```text
add 1 ok Самокат
add 2 fail Велосипед
list
focus 1
show_focus
remove 1
show_focus
quit
```

Ожидаемый вывод приведён ниже.

```text
added
error: inspection failed
1 Самокат
focused
1 Самокат
removed
expired
```
